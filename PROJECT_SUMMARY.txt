PROJECT SUMMARY: INTELLIGENT LAND MEASUREMENT APP (MONGODB COMPASS INTEGRATED)
================================================================================

1. TECH STACK & SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
- Framework: Flutter (Dart 3.3+)
- Backend: Node.js (v18+) with Express 5 & Mongoose 9
- Database: MongoDB Compass / Local MongoDB instance
  * Connection URI: mongodb://127.0.0.1:27017/intelligent_land_measurement
  * Collections: users (Account credentials), lands (Land surveys & plots)
- Communication:
  * lib/services/api_service.dart: Intelligent environment auto-discovery
    (Android Emulator: 10.0.2.2:5000, Desktop/Local: 127.0.0.1:5000, Wi-Fi: 192.168.1.4:5000)
  * lib/services/auth_service.dart: User session manager
  * lib/screens/field_storage.dart: Dual storage (SharedPreferences cache + MongoDB sync)

3. COMMANDS TO RUN
--------------------------------------------------------------------------------
1. To start the MongoDB backend server:
   Double-click start_backend.bat OR run:
   node server.js

2. To run the Flutter App on USB-connected Android phone:
   adb reverse tcp:5000 tcp:5000
   flutter run

3. To view data in MongoDB Compass:
   Connect to: mongodb://127.0.0.1:27017
   Select database: intelligent_land_measurement
